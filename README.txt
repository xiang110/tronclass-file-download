TronClass 教材連結助手 1.0
1. 解壓縮 ZIP。
2. Chrome 開啟 chrome://extensions/，啟用開發人員模式。
3. 點選「載入未封裝項目」，選擇包含 manifest.json 的資料夾。
4. 登入輔大 TronClass，開啟課程。右下角會出現教材下載連結按鈕；能辨識課程 ID 時自動開啟面板並查詢。
5. 若無法辨識課程 ID，手動輸入，例如 396330。
6. 可複製全部網址、個別開啟網址或匯出 CSV。擷取頁面連結可補充目前 DOM 內的附件。
限制：使用已知 coursewares API 和 reference blob 路徑；並未在登入後的實際平台測試。只列出 API 標示可下載且有 reference_id 的教材；不包含未公開、無權限、其他活動類型或沒有 reference_id 的資源。無法保證取得後端實體儲存網址。無外部傳輸、無 Cookie 讀取、無額外套件。
